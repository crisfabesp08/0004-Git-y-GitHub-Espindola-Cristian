# 0004 - Git y GitHub Espindola Cristian

Este repositorio reúne los trabajos prácticos realizados en las clases de **DeepNote**, **Python Repaso** y **Python Librerías**, organizados en carpetas individuales para facilitar la consulta y mantener una estructura clara.  
La actividad forma parte del proceso de aprendizaje en el uso de **Git y GitHub** como herramientas de control de versiones y colaboración en proyectos de ciencia de datos.

## 📂 Estructura del repositorio
- **Deepnote/**
  - `0001-Deepnote-Espindola-Cristian.ipynb` → Ejercicios iniciales en la plataforma DeepNote.
- **Python-Repaso/**
  - `0002-Python-Repaso-Espindola-Cristian.ipynb` → Repaso de conceptos fundamentales de Python.
- **Python-Librerias/**
  - `0003-Python-Librerias-Espindola-Cristian.ipynb` → Uso de librerías aplicadas a ciencia de datos.

## 🎯 Objetivos
- Introducir el uso de **Git y GitHub** como herramientas de control de versiones.  git
- Aprender a registrar cambios y gestionar versiones de un proyecto.  
- Comprender la importancia de mantener un historial organizado del desarrollo.  
- Facilitar el trabajo colaborativo en proyectos de ciencia de datos.

## 🛠️ Metodología
- Creación de un repositorio público en GitHub.  
- Organización de los notebooks en carpetas temáticas.  
- Registro de cambios mediante commits y push.  
- Ejercitación de conceptos de colaboración con ramas y Pull Requests.
